# 🎂 Magical Birthday Surprise Web ✨

A beautiful, interactive, and fully responsive birthday surprise web application designed with a modern dark-neon aesthetic.
It takes the user through a step-by-step magical journey filled with music, lights, memories, and virtual celebrations.

## 🌟 Key Features

* **Pitch Black Start:** Opens with a dark, mysterious theme that slowly fades into a glowing neon ambient background upon activation.
* **Automatic 3D Carousel:** A beautifully aligned slideshow of 5 photo cards that rotates on a set timer without needing any user clicks.
* **Delayed Action Button:** The "Next Stage" button appears smoothly only after a few seconds of the slideshow, encouraging the user to view
  the pictures first.
* **Interactive Virtual Cake:** Includes a match-lighting step, floating particles, and a sliding neon knife animation to cut the birthday cake.
* **Pop-on-Cut Balloons:** Floating balloons rise up from the bottom and instantly pop with a satisfying confetti burst when the cake is sliced.
* **Typewriter Letter:** Displays a sentimental, slow-typing final letter to finish the celebration on an emotional note.

## 📁 How to Add Your Own Photos

To display your personalized images inside the automatic carousel, follow these simple steps:

1. Create a folder named `images` in the root directory (where your `index.html` is located).
2. Drop your favorite 5 photos into that folder.
3. Rename the images exactly as: `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg`, and `5.jpg`.

*Note: Ensure all your image file extensions are lowercase `.jpg` format.*

## 🛠️ Built With

* **HTML5** - Structure and layout definition.
* **Tailwind CSS** - Modern, responsive styling and glowing neon utilities.
* **GSAP (GreenSock Animation Platform)** - Fluid 3D card movements, custom timing sequences, and transitions.
* **HTML5 Canvas** - Rendering dynamic fireflies and celebratory confetti particles.
* **YouTube Iframe API** - Background ambient music execution.
